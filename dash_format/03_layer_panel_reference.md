             └── Attribute Groups

## Layer Controls

- Visibility

## Attribute Types
- Categorical values
- Range sliders

## Behaviour
- Section collapse independent of layer visibility.
- Layer visibility independent of accordion state.
- Attribute values individually toggleable.
