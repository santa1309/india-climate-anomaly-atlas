# Dashboard Layout Reference

## Purpose
Defines the overall dashboard composition and visual language.

## Layout Structure
- Top App Bar (branding, profile)
- Left persistent sidebar
  - Filters
  - Layer controls
- Center interactive map (primary focus)
- Right insights/opportunities panel
- Floating map controls
- Bottom action bar (reports / primary CTA)

## Design Principles
- Map occupies ~65–75% width.
- Side panels remain visible.
- White cards over light map.
- Primary brand color: Teal (#0BAFAF) for Agri/Forestry.
- Follow SatSure spacing, typography and elevation.

## Important
Use this as a visual layout reference only.
Do **not** copy the sample content, labels, villages, or data.
