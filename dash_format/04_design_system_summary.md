# SatSure Design System Summary

## Theme
Default: Teal (#0BAFAF)
Aviation only: Purple (#6E3BD1)

## Font
- Manrope
- Roboto for charts

## Spacing
8px base grid.

## Border Radius
4px

## Elevation
Cards: 1
Buttons: 2
Dialogs: 16
Tooltips: 24

## Dashboard Rules
- Sticky AppBar
- Persistent Drawer
- White cards
- Consistent spacing
- Semantic status colors
- Responsive MUI layout

## Buttons
Primary: contained
Secondary: outlined
Tertiary: text
