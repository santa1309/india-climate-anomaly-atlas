# Map Popover Reference

## Purpose
Defines the structure of a marker tooltip.

## Layout
- Rounded white card
- Soft shadow
- Small colored marker beside title

## Fields
1. Title (primary)
2. Attribute label/value rows
   - Species
   - Age
   - Area
   - Status

## Typography
- Title: bold
- Labels: secondary text
- Values: emphasized and right aligned

## Important
Reuse only the structure and visual hierarchy.
Do not reuse the example values.
